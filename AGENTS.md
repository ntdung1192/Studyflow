# StudyFlow Pro - AI Instructions

## Project
StudyFlow Pro is a full-stack study management and team collaboration application.

## Technology
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB + Mongoose
- State management: Context API + Redux Toolkit
- Authentication: JWT + bcrypt

## Rules
1. Follow the existing project architecture.
2. Do not introduce dependencies without explaining why.
3. Do not duplicate existing functionality.
4. Keep frontend, backend and database contracts consistent.
5. Validate all incoming API data.
6. Enforce authentication and authorization on the backend.
7. Never expose secrets or commit .env files.
8. Write maintainable and readable code.
9. Add appropriate tests for new functionality.
10. Do not modify unrelated files without permission.
11. Explain significant changes before implementing them.
12. Do not claim tests passed unless they were actually executed.

## Git
- Use feature branches.
- Use Pull Requests to merge into develop.
- Never push directly to main.
- Use conventional commit messages.

## Collaboration
- Personal data must remain private.
- Group data is visible only to authorized active members.
- Only group members can access group resources.
- Only authorized roles can manage group membership.
